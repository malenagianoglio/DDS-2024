Portfolio Web – Proyecto Personal (Ficticio)
Link: https://portfolio-malenagianoglio.netlify.app/

- Descripción:
Este repositorio contiene un portfolio web personal desarrollado como proyecto ficticio, creado con el objetivo de practicar maquetado web, diseño visual y estructura de sitios frontend.
La información presentada (experiencias laborales, proyectos y datos simulados) no corresponde a experiencias reales, sino que fue creada únicamente con fines demostrativos y educativos.

- Objetivo del proyecto:
Practicar HTML y CSS
Diseñar la estructura de un portfolio profesional
Aplicar diseño responsivo
Trabajar buenas prácticas de maquetado y estilos

- Tecnologías utilizadas:
HTML5
CSS3
Flexbox
Diseño responsivo

-Funcionalidades:
Sitio web estático con secciones típicas de un portfolio profesional:
Inicio
Sobre mí
Proyectos (ficticia)
Contacto

⚠️ Aclaración importante:

Este proyecto es ficticio y académico.
